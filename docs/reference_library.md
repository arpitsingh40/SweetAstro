# SweetAstro Reference Library — Curated Source Bibliography

> **Knowledge extraction for every entry**: see `docs/knowledge/` — four files
> (`01_classical_canon.md` T1–T2, `02_modern_specialized.md` T3–T4,
> `03_applied_systems.md` T5–T9, `04_vastu_knowledge_base.md` full Vastu corpus)
> distilling each source's core knowledge and its engine rule-category mapping.

**Purpose**: provenance sources for the rule engine, remedy catalog, and verification
of classical technique.

No titles were invented. Entries are one of three kinds:
- **Known works** — a specific published book, classical text, or verified author.
- **(verify edition)** — a real text/tradition whose translator, publisher or year
  varies by reprint; confirm bibliographic details before quoting.
- **Topic entries** — a descriptive subject line (e.g., "Transit techniques",
  "Yogini Dasha") naming an established technique to be sourced from the T1/T2
  texts; treat it as a search key, not as a confirmed book title.

**How to read the tiers** (authority-based, not retail review scores — review ratings
were deliberately not scraped or invented):

| Tier | Meaning | Use in SweetAstro |
|---|---|---|
| T1 | Primary classical Sanskrit source | Rule provenance (highest authority) |
| T2 | Critical translation / commentary of a T1 text | Rule provenance once edition is verified |
| T3 | Modern standard treatise by an established author | Secondary rules, technique cross-check |
| T4 | Specialized system (Jaimini, KP, Nadi, Tajika, Ashtakavarga) | System-specific rules |
| T5 | Muhurta / Prashna / electional | Timing rules |
| T6 | Vastu Shastra (classical and modern) | Vastu module (future) |
| T7 | Remedies: Lal Kitab, mantra, gemstone, yantra, service | Remedy catalog sourcing |
| T8 | Nakshatra / Ayurvedic / medical astrology | Health-topic rules |
| T9 | Scholarly/historical studies and cross-system checks | Sanity checks, dating, translation quality |

**Caveat on editions**: classical titles exist in many reprints of varying quality.
Verify translator, publisher, and edition before citing a verse. Prefer editions from
Motilal Banarsidass, Sagar, Ranjan, Chaukhamba, and university presses for T1/T2.

## How to use this list in SweetAstro

1. **Rule provenance**: add selected T1/T2 sources to the `source.book` enum in
   `docs/rule_schema.json` before writing new rules; never cite a book not listed
   there.
2. **Remedy catalog**: T7 entries justify remedy categories (alignment, mantra,
   ritual, donation, Lal Kitab, reference). Keep the existing safety gates.
3. **Verification order**: when two sources disagree, prefer T1 over T3, and prefer
   a verified T2 edition over a reprint of unknown provenance.
4. **Do not** present tier as a review rating; it reflects textual authority for
   rule-making only.
